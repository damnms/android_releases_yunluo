# android_releases_yunluo

Downloads of the unofficial LineageOS 24.0 (Android 17) build for the
Xiaomi Redmi Pad (yunluo). The builds are on the
[releases page](https://github.com/damnms/android_releases_yunluo/releases),
each with release notes, changelog and checksums.

## OTA updates

`yunluo.json` is the update list for the LineageOS Updater (Settings →
System → Updates). Builds from 20261117 on read it through
`lineage.updater.uri`; it points to the zip of the latest GitHub release.
Older builds have to be updated once by sideload or with "Install local
update".

Sources: [device tree](https://github.com/damnms/android_device_xiaomi_yunluo),
[local manifest](https://github.com/damnms/android_local_manifests_yunluo).
